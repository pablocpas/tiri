# Parity inventory

Generated by `tiri-parity/inventory.sh`. Do not edit by hand — edit the script, or
port a function and rerun.

The denominator the fuzz cannot give us. A campaign's seed count describes its budget
as much as the compositor: raising `SCRIPT_LEN` from 14 to 28 turned five clean seeds
into five divergent ones without a line of layout code changing. This list does not
move when a constant does.

"Cited" means tiri names the function where it implements it. It proves the rule was
read, not that it was read correctly; the fixtures prove that. Coverage of the map,
not of the ground.
